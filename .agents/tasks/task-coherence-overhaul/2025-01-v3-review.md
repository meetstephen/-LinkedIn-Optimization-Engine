# Voice system coherence overhaul and engagement prediction (v3)

Both issues from the v2 review are resolved. The scheduler pipe now has a complete consumer — an expanded preview card with day/slot selectors that saves to Library and schedules in one click. The proper noun false-positive concern is addressed with a 30-entry stoplist (`_NON_PLACE_PROPER_NOUNS`) that filters tech brands, social platforms, titles, and day/month names before awarding the specificity bonus.

**Watch for:** The scheduler preview renders piped content into raw HTML (`unsafe_allow_html=True`) without escaping — a post containing `<img onerror=...>` or `<script>` would render unsanitized (confirmed, low severity given content is AI-generated, but violates defense-in-depth).

## High-level view

The prompt alignment across all six modules is consistent and mirrors `core/voice.py`'s STRUCTURE_RULES. Every module seeds its few-shot selection deterministically via MD5 of the first 50 input characters. `engagement_toolkit` and `engagement_intelligence` now use the specialized `get_hook_examples()` and `get_comment_examples()` helpers respectively.

The engagement prediction scorer has 21 tests covering bounds, all five factors, and determinism. The proper noun stoplist won't catch every non-place noun, but the +2/20 bonus is small enough that residual false positives don't materially distort scores.

## Missing HTML escape in scheduler preview card

The scheduler's quick-schedule expander renders piped content directly into HTML:

```python
f"{_prefill[:500].replace(chr(10), '<br>')}"
```

Compare with `post_generator.py`'s LinkedIn preview, which properly escapes:

```python
def _fmt(text: str) -> str:
    return _html.escape(text).replace('\n', '<br>')
```

And the polish output in the same file:

```python
f"white-space:pre-wrap;'>{_html.escape(_polished)}</div>",
```

If a future code path allows arbitrary text into `scheduler_pipe_content`, or a user manipulates session state via browser devtools, the unescaped render becomes an XSS vector.
